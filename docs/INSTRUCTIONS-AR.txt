تعليمات QASSIMZ Producer
=========================

برنامج واحد لإنتاج الفيديوهات والسلاسل من أول الفكرة لحد النشر:
الأفكار ← السكريبت ← الصور والموسيقى والملحقات ← المهام ← النشر، ومعاه مساعد ذكاء اصطناعي.

البداية:
 1) اعمل «سلسلة» من الشريط الجانبي (أو ابدأ بحلقات منفردة).
 2) «الأفكار»: لوحة مفتوحة، دبل كليك في أي مكان تكتب فكرة، وتحوّلها لحلقة بضغطة.
 3) «الحلقات»: كل حلقة كارت. اسحبه بين المراحل: فكرة ← بحث ← سكريبت ← تسجيل ← مونتاج ← جاهز ← منشور.
 4) افتح الحلقة واكتب السكريبت مشهد مشهد، واربط بكل مشهد الصور والموسيقى بتاعته.
    المدة بتتحسب لوحدها، وفيه «تيليبرومبتر» للتسجيل.
 5) «المكتبة»: كل ملفاتك (صور، فيديو، موسيقى، جرافيك، MOGRT…) بتاجات وبحث.
 6) «تصدير»: بيعمل فولدر جاهز للمونتاج (السكريبت Word + Markdown + الملفات متقسمة + edit-list).

الذكاء الاصطناعي (⚙ الإعدادات ← الذكاء الاصطناعي):
 - GitHub Models: مجاني. اعمل توكن من GitHub بصلاحية Models (Read) والصقه.
 - Claude: حط مفتاح Anthropic API.
 - Ollama / LM Studio: موديل محلي على جهازك.
 بيعمل: اقتراح أفكار، هيكل سكريبت كامل، إعادة صياغة (أقصر، أطول، عامية، كوميدي)،
 اقتراح المرئي والموسيقى لكل مشهد، مهام الإنتاج، عناوين ووصف وتاجات وأفكار ثمبنيل،
 تلخيص المصادر، تاجات للصور، وتجميع الأفكار المبعترة.
